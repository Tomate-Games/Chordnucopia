# Chordnucopia

Chordnucopia is a free and open-source software that generates mostly random chords based on a starting note and a stated length for the chord. There are also other configurations present on the program, such as adding a playback delay for each key and a history that stores the last chords generated for reproduction.

## Warning

As this software is not code signed by a developer's certificate, most operating systems will flag it as a possibly malicious program. Please note that the source code contains no malicious intent and is available for review as proof.

## Features

- Mostly random chord generation;
- History storing and playback options;
- Constant playback delay for each key;
- Configurable starting note and number of notes for each chord;
- Simple, fast and lightweight.
